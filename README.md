# Netflix-Dataset-Analysis
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles Dataset from Kaggle.
The goal is to explore patterns, trends, and insights about the types of content available on Netflix — including movies and TV shows, their release years, genres, countries of origin, and more.

📊 Dataset Information

Dataset source:
Netflix Shows Dataset – Kaggle (by shivamb)

File used: netflix_titles.csv
Number of records: ~8,800 titles
Columns include:

show_id — Unique ID for each title

type — Movie or TV Show

title — Name of the show

director, cast — Key people involved

country, release_year, date_added — Origin and release details

rating, duration, listed_in, description — Content details

🧠 Objectives

Perform data cleaning and handle missing values

Analyze distribution of movies vs TV shows

Find most common genres and top producing countries

Visualize release year trends

Examine content ratings and durations

(Optional) Build a simple text classification model predicting content type from descriptions

🧩 Tools & Libraries Used

Python 🐍

Pandas and NumPy for data handling

Matplotlib and Seaborn for visualization

Scikit-learn for basic ML modeling

Jupyter Notebook for analysis presentation
